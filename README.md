# Været

Personlig værside med data direkte fra Meteorologisk institutt (api.met.no):
varsel, nowcast, farevarsler, MET-radar, luftkvalitet, hav og tidevann,
målestasjon (MET Frost) og en føre-assistent for gå, løpe, sykle og kjøre.

Åpne siden: https://andedkristiansen-ux.github.io/vaer/

Datakilder: MET Norway (CC BY 4.0), Open-Meteo, RainViewer, Kartverket, Esri.
